## Why Sinsajo?

<CardGrid stagger>
  <Card title="Real-time" icon="rocket">
    ~150–300ms end-to-end latency. See text as you speak, with Voice Activity Detection (Silero VAD v5) sending only speech segments.
  </Card>
  <Card title="100% Private" icon="approve-check-circle">
    Self-hosted Rust server. No API keys, no cloud. Your audio never leaves your network. Optional local WAV/OGG recording.
  </Card>
  <Card title="Multi-platform" icon="laptop">
    Flutter client for Android, iOS, Desktop and **Web**. Rust server runs anywhere — Docker, bare metal, VPS.
  </Card>
  <Card title="Spanish First" icon="translate">
    Native Spanish punctuation and multi-language target selection (en/es/fr/de/pt). English via Parakeet, translation via Canary.
  </Card>
</CardGrid>

## How it works

```
┌─────────────────┐         WebSocket          ┌──────────────────┐
│  Flutter Client │ ◄─────────────────────────►│   Rust Server    │
│  (Dart/Silero)  │    PCM 16-bit / JSON       │ (transcribe-rs)  │
└─────────────────┘                            └──────────────────┘
       │                                                 │
       │ Silero VAD v5                                   │ ONNX Model
       │ (ONNX Runtime)                                  │
       ▼                                                 ▼
 ┌─────────────────┐                             ┌──────────────────┐
 │  AudioService   │                             │  Canary 180M     │
 │  + vad package  │                             │  Flash /         │
 │  (ML-based)     │                             │  Parakeet TDT    │
 └─────────────────┘                             └──────────────────┘
```

<Steps>

1. **Capture** — Flutter records PCM 16-bit @ 16kHz
2. **Detect** — Silero VAD v5 detects speech (ONNX Runtime)
3. **Transmit** — Only speech chunks sent over WebSocket
4. **Transcribe** — Rust server runs Canary 180M Flash or Parakeet TDT 0.6B (Int8)
5. **Display** — Real-time text + optional server-side WAV/OGG recording

</Steps>

## Get started in 3 minutes

<Tabs>
  <TabItem label="Docker (recommended)">
    ```bash
    docker pull lutgaru/sinsajo-server:latest
    docker run -p 8765:8765 \
      -v sinsajo_models:/app/models \
      -v sinsajo_records:/app/records \
      lutgaru/sinsajo-server:latest
    # Server on ws://localhost:8765
    ```
    Or with Compose — see [Server Guide](/Sinsajo/guides/server/).
  </TabItem>
  <TabItem label="Cargo">
    ```bash
    git clone https://github.com/lutgaru/Sinsajo.git
    cd Sinsajo/server
    cargo run --release -- --model ParakeetTDT --autodownload-model
    ```
  </TabItem>
  <TabItem label="Flutter Client">
    ```bash
    cd sinsajo_client
    flutter pub get
    # update lib/providers/transcription_provider.dart -> kWsUrl
    flutter run
    ```
    Or open the [Web App](/Sinsajo/app/) directly in your browser.
  </TabItem>
</Tabs>

## At a glance

| Metric | Value |
|--------|-------|
| Latency | ~150–300ms chunk → text |
| CPU | ~20–40% (1 core) |
| RAM | ~500MB (Int8 quantized) |
| Accuracy | ~95% clean Spanish |
| Bandwidth | ~256KB/s (PCM, VAD reduces ~60%) |

<Aside title="APK Distribution">
  APKs are **not** stored in `git`. Every tagged release `client/v*` builds the APK via GitHub Actions and attaches it to the GitHub Release. Link directly to `https://github.com/lutgaru/Sinsajo/releases/latest/download/app-release.apk` from your landing buttons or share a QR.
</Aside>
